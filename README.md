# ✂ BARBER - Sistema de Reservas para Barberías

Sitio web sofisticado con diseño minimalista para reservar citas en múltiples barberías, con sistema de calificaciones para barberos y establecimientos.

## 🌟 Características

- **4 Barberías Únicas**: Selecciona entre diferentes estilos y ubicaciones en Madrid
- **12 Barberos Especializados**: 3 barberos profesionales por barbería con especialidades distintas
- **Sistema de Calificaciones**: Califica tanto barberías como barberos (1-5 estrellas)
- **Reserva de Citas**: Sistema completo de reservas con selección de fecha, hora y servicio
- **Diseño Moderno**: Interfaz minimalista con animaciones sofisticadas y tema oscuro elegante
- **Totalmente Responsive**: Funciona perfectamente en dispositivos móviles y de escritorio

## 🚀 Cómo Usar

1. **Abrir el sitio web**: Abre `index.html` en tu navegador web
2. **Explorar Barberías**: Navega por las 4 barberías disponibles
3. **Seleccionar Barbero**: Haz clic en una barbería para ver sus barberos
4. **Reservar Cita**: Haz clic en un barbero para abrir el formulario de reserva
5. **Calificar**: Usa los botones "Calificar" para valorar barberías y barberos

## 🎨 Diseño

- **Colores**: Tema oscuro (#0f0f0f) con acentos dorados (#d4af37)
- **Tipografía**: Segoe UI para una apariencia moderna y limpia
- **Animaciones**: Transiciones suaves y efectos hover elegantes
- **Layout**: Grid responsive con cards para barberías y barberos

## 💻 Tecnologías

- HTML5 semántico
- CSS3 con variables personalizadas y animaciones
- JavaScript vanilla (sin dependencias externas)
- Diseño responsive sin frameworks

## 📱 Funcionalidades Principales

### Sistema de Reservas
- Formulario completo con validación
- Selección de fecha (mínimo día siguiente)
- Horarios disponibles de 9:00 a 20:00
- Múltiples tipos de servicios

### Sistema de Calificaciones
- Calificación interactiva con estrellas
- Actualización en tiempo real de promedios
- Contador de valoraciones totales
- Feedback visual descriptivo

### Navegación
- Menú de navegación sticky
- Scroll suave entre secciones
- Indicador de sección activa
- Botón para volver a la lista de barberías
